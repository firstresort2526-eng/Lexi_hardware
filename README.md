# My Project

This project has multiple components:

## Parts

- [Part 1: Projector](2/README.md) - Show words on a LCD. With a strong backlight and lens, it can project words out.
- [Part 2: Camera](3/README.md) - Capture images from RPi camera, which then goes through part 3
- [Part 3: Coordinate Conversion](4/README.md) - Detects the pencil tip coordinates from the captured image

Each part has its own requirements and setup instructions in its respective folder.
